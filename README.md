## 📌 О проекте

**Своё.Шеф** — это платформа от РСХБ для развития ресторанного бизнеса. Её цель — помочь ресторанам оптимизировать работу, снизить издержки и привлечь новых клиентов. 

### 🎯 Цель проекта

Помочь ресторанам и шеф-поварам:
- Планировать сезонные обновления меню на основе визуальной картины сезонности
- Ускорить поиск сезонных ингредиентов и подходящих фермеров
- Оптимизировать закупки и снизить издержки
- Работать напрямую с фермерами без посредников

### 👥 Целевая аудитория

- Шеф-повара ресторанов авторской кухни
- Рестораторы и управляющие
- Фермеры и производители натуральных продуктов

---

## ✨ Основные возможности

### 1. Умный поиск продуктов
- Поиск с исправлением опечаток и поддержкой синонимов
- Фильтрация по сезону, категории, региону и типу продукта
- Сортировка по сезону, категории, цене

### 2. Аналитика сезонности
- Календарь сезонности 
- Распределение продуктов по категориям
- Доступность продуктов по категориям


### 3. Анализ PDF меню
- Загрузка PDF-файла с меню ресторана
- Автоматическое распознавание ингредиентов
- Подбор подходящих продуктов от фермеров
- Сезонные рекомендации

### 4. Рекомендации для блюд
- Анализ ингредиентов популярных блюд (борщ, окрошка, щи, уха, пельмени, блины)
- Проверка доступности ингредиентов в сезон
- Предложения сезонных замен
- Советы шеф-повару

### 5. Избранное и корзина
- Сохранение любимых продуктов в избранное
- Формирование корзины заказа
- Оформление заказа фермерам
