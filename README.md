## О проекте

**Своё.Шеф** — это платформа от РСХБ для развития ресторанного бизнеса. Её цель — помочь ресторанам оптимизировать работу, снизить издержки и привлечь новых клиентов.
### Основные возможности

- **Умный поиск продуктов** - поиск с исправлением опечаток и синонимами
- **Аналитика сезонности** - тепловая карта, таймлайны, прогноз цен
- **Анализ PDF меню** - автоматическое распознавание ингредиентов
- **Рекомендации для блюд** - анализ ингредиентов и сезонные замены
- **Избранное** - сохранение любимых продуктов
- **Корзина заказа** - формирование заказа фермерам
